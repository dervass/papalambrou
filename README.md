# 🪵 Papalambrou Ioannis S.A.

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deployment-black?style=flat&logo=vercel)](https://papalambrou.vercel.app/)
[![Next.js](https://img.shields.io/badge/Next.js-Project-000000?style=flat&logo=next.js)](https://nextjs.org/)

**Papalambrou Ioannis S.A.** is a modern, high-performance web application built for the premier solid fuel and transport company in Grevena, Greece. Founded in 1995, the company focuses on providing high-quality firewood, charcoal, and reliable national transportation services.

---

## ✨ Features

-   **Premium UI/UX**: Mobile-first design with smooth transitions and professional wood-themed aesthetics.
-   **Product Catalog**: Detailed overview of solid fuel products (Firewood, Charcoal, Pellets).
-   **National Transport**: Information about specialized transport services across Greece with a private fleet.
-   **Interactive Gallery**: High-quality image gallery showcasing products and company infrastructure.
-   **Contact & Location**: Integrated Google Maps and direct contact channels for seamless communication.
-   **Performance Optimized**: Built with Next.js 15+ for lightning-fast loading and SEO excellence.

---

## 🛠️ Tech Stack

-   **Frontend**: Next.js 15+ (App Router), React 19
-   **Styling**: Tailwind CSS v4
-   **Components**: Swiper.js (for gallery interactions)
-   **Icons**: Custom SVG Icons
-   **Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or higher)
-   [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dervass/papalambrou.git
   cd papalambrou
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
