# 🪵 Παπαλάμπρου Ιωάννης Α.Ε. | 100% Static HTML/CSS Website

[![Static HTML5](https://img.shields.io/badge/HTML5-100%25-orange?style=flat&logo=html5)](https://papalamprouae.gr/)
[![CSS3](https://img.shields.io/badge/CSS3-Pure_Tailwind-blue?style=flat&logo=css3)](https://papalamprouae.gr/)
[![JavaScript Free](https://img.shields.io/badge/JavaScript-0%25_JS_Free-brightgreen?style=flat)](https://papalamprouae.gr/)

**Παπαλάμπρου Ιωάννης Α.Ε.** is a lightweight, high-performance, 100% static HTML5/CSS3 website for the premier solid fuel and national transport company based in Grevena, Greece (founded in 1995).

---

## ⚡ Highlights

- **100% JavaScript-Free**: Zero client-side scripts, zero framework overhead, ultra-fast load times.
- **Pure CSS Interactive Gallery**: Photo category switching using HTML radio inputs and CSS peer selectors.
- **Fully Responsive & Modern**: Mobile-first layout with wood-themed aesthetic and Tailwind CSS utilities.
- **SEO & Schema.org Ready**: Includes metadata, Open Graph cards, and JSON-LD structured business markup.

## 🚀 How to View or Host

### Local Viewing
Double click `index.html` or open it directly in any web browser (`file:///path/to/index.html`).

### Local Web Server (Optional)
You can serve the directory with any standard HTTP server, for example:
```bash
npx serve .
# OR
python3 -m http.server 8000
```

### Static Hosting Deployment
Deploy directly to any static host (GitHub Pages, Vercel, Netlify, Cloudflare Pages, AWS S3, Apache/Nginx web server) without requiring Node.js or server-side processing.
